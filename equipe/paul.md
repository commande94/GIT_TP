## Quiz

1. Juste après `git commit`, où se trouve mon commit ? Dans le dépôt local du Codespace, sans être encore partagé sur GitHub.
2. Juste après `git push`, où se trouve-t-il ? Sur GitHub, ce qui permet à l'équipe de le récupérer.
3. Que se passe-t-il si je supprime mon Codespace après un commit mais sans push ? Le commit est perdu, car il n'a jamais été synchronisé avec le dépôt distant.
