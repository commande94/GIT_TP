## Quiz

1. Après `git commit`, le commit se trouve dans l'historique local du Codespace.
2. Après `git push`, le commit est envoyé sur GitHub.
3. Si le Codespace est supprimé avant le push, le commit local est perdu.

## Stash

`git stash` met temporairement de côté les modifications non commitées.
On peut les récupérer ensuite avec `git stash pop`.
